# Campaña de reactivación de base fría

## Objetivo
Reactivar contactos que alguna vez consultaron por un idioma y pueden no recordar IKARUGA Servicios, sus redes o el canal de contacto. Cada email vuelve a presentar la marca, muestra los idiomas disponibles y lleva a una conversación por WhatsApp.

## Enfoque creativo
- Tono institucional, cercano y claro.
- Cada mail funciona de manera independiente porque la persona puede abrir solo uno.
- No se asume el idioma consultado.
- No se prometen resultados ni se agregan precios, cuotas, fechas, cupos, módulos, horas o certificaciones sin validación vigente.
- La acción principal es hablar por WhatsApp con IKARUGA o con el asesor definido por marketing.

## Cadencia sugerida
- Día 0: Reencuentro institucional y presentación de IKARUGA.
- Día 3: Idiomas disponibles y orientación para elegir.
- Día 7: Cómo se cursa y por qué conviene hablar con un asesor.
- Día 12: Cierre respetuoso, canales oficiales y puerta abierta.

## Reglas antes de activar
- Validar que la base está habilitada para comunicaciones.
- Excluir bajas, rebotes, alumnos actuales, inscriptos y gestiones activas.
- Reemplazar `[LINK_DE_WHATSAPP_CENTRAL_O_DEL_ASESOR]` por el link real que defina marketing.
- Reemplazar `[ENLACE_DE_BAJA]` por el enlace de baja de Doppler.
- Revisar asunto y preheader dentro de Doppler antes del envío.
- No se incorporó descuento; solo debe agregarse con vigencia, cursos aplicables y validación comercial real.
