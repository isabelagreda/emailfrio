# Campaña de reactivación de base fría

## Objetivo
Reintroducir IKARUGA Servicios a contactos que pueden no recordar una consulta anterior y llevarlos a WhatsApp.

## Cadencia
- Día 0: Conocé IKARUGA.
- Día 3: Idiomas y orientación.
- Día 7: Propuesta académica.
- Día 12: Cierre respetuoso.

## Reglas antes de activar
- Validar que la base está habilitada para comunicaciones.
- Excluir bajas, rebotes, alumnos actuales, inscriptos y gestiones activas.
- Usar un enlace central de WhatsApp o asignar asesor antes del envío.
- Reemplazar los marcadores de WhatsApp y baja en cada HTML o dentro de Doppler.
- No se incorporó descuento; solo debe agregarse con vigencia, cursos aplicables y validación comercial real.
